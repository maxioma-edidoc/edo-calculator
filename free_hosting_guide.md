# Бесплатные варианты размещения калькулятора без VPN из Беларуси

Поскольку калькулятор представляет собой **чисто статический сайт** (HTML, CSS, JS без бэкенда и баз данных), для него есть отличные бесплатные хостинги, которые предоставляют бесплатные домены третьего уровня, бесплатный HTTPS (SSL) и при этом стабильно открываются в Беларуси с любых устройств (и iPhone, и ПК с Windows).

Вот 3 лучших бесплатных варианта:

## 1. GitHub Pages (github.io) — Самый популярный и стабильный
* **Цена**: Бесплатно навсегда.
* **Домен**: `yourname.github.io/repository-name` (или можно привязать кастомный домен бесплатно).
* **Как сделать**:
  1. Скачайте ZIP-архив проекта через меню `⋯` -> **Download as ZIP** в управлении проектом.
  2. Создайте бесплатный репозиторий на GitHub.
  3. Загрузите файлы в репозиторий.
  4. В настройках репозитория (Settings -> Pages) включите GitHub Pages.
* **Почему подходит**: Домены github.io стабильно открываются в РБ без блокировок.

## 2. Netlify (netlify.app) — Быстрый деплой за 1 минуту
* **Цена**: Бесплатно (до 100 ГБ трафика в месяц).
* **Домен**: `random-name.netlify.app` (имя можно изменить в настройках на любое свободное, например `edidoc-calc.netlify.app`).
* **Как сделать**:
  1. Скачайте ZIP-архив проекта через меню `⋯` -> **Download as ZIP**.
  2. Зайдите на [netlify.com](https://www.netlify.com/) (вход бесплатный, можно через GitHub или email).
  3. Перетащите распакованную папку со статическими файлами в зону загрузки на главной странице Netlify Drop.
  4. Сайт мгновенно опубликуется и выдаст готовую рабочую ссылку с HTTPS.
* **Почему подходит**: Бесплатно, выдает красивый поддомен, работает у всех пользователей.

## 3. Vercel (vercel.app) — Аналог Netlify с мгновенным обновлением
* **Цена**: Бесплатно для некоммерческих проектов.
* **Домен**: `project-name.vercel.app`.
* **Как сделать**: Аналогично Netlify, загрузите архив или подключите репозиторий GitHub.
