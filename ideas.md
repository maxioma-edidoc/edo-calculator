# Калькулятор экономии времени на ЭДО — Дизайн-философия

## Три подхода

### 1. **Минималист с энергией** (Probability: 0.08)
Чистый, воздушный интерфейс с яркими акцентами. Фокус на скорости и простоте. Используется максимум белого пространства, тонкие линии, современный шрифт. Акцентный цвет (например, яркий зелёный или оранжевый) подчёркивает действия и результаты.

### 2. **Корпоративный с доверием** (Probability: 0.07)
Серьёзный, профессиональный вид. Синие и серые тона, чёткие структуры, карточки с тенями. Вызывает доверие и надёжность. Подходит для B2B аудитории.

### 3. **Динамичный с прогрессом** (Probability: 0.06)
Визуально живой интерфейс с анимациями, прогресс-барами, иконками. Использует теплые цвета (оранжевый, жёлтый) и холодные (синий). Ощущение движения и достижения. Каждый шаг визуально отмечен.

## Выбранный подход: **Динамичный с прогрессом**

### Design Movement
**Современный B2B SaaS с акцентом на результаты и прозрачность**. Вдохновлено интерфейсами финтех-приложений и калькуляторов экономии (типа Stripe Pricing Calculator). Фокус на визуальной прогрессии, ясности и мотивации пользователя.

### Core Principles
1. **Прозрачность прогресса** — пользователь всегда видит, на каком этапе он находится (шаг X из Y)
2. **Результат-ориентированность** — финальный экран с яркими метриками и рекомендациями
3. **Минимальное когнитивное напряжение** — одна тема в фокусе, чёткие варианты ответов
4. **Позитивная энергия** — тёплые акценты, плавные переходы, ощущение движения вперёд

### Color Philosophy
- **Основной фон**: Светлый нейтральный (почти белый, `oklch(0.98 0.001 286)`)
- **Акцентный цвет**: Яркий оранжевый (`oklch(0.65 0.25 45)`) — энергия, действие, оптимизм
- **Дополнительный**: Мягкий синий (`oklch(0.55 0.15 250)`) — доверие, информация
- **Успех**: Зелёный (`oklch(0.7 0.2 140)`) — готовность, позитив
- **Предупреждение**: Жёлтый (`oklch(0.75 0.18 80)`) — внимание, переход
- **Текст**: Тёмный серый (`oklch(0.25 0.01 0)`)

### Layout Paradigm
- **Вертикальный прогресс**: Экран разделён на три зоны:
  1. **Верх**: Прогресс-бар (шаг X из Y) + название этапа
  2. **Середина**: Вопрос + варианты ответов (радио-кнопки, чекбоксы)
  3. **Низ**: Кнопка "Далее" (активна только при ответе) + опциональная кнопка "Назад"
- **Результаты**: Карточки с метриками (часы, документы, процент готовности) + текстовое объяснение + рекомендации

### Signature Elements
1. **Прогресс-бар с числами** — визуально показывает прогресс (например, "3 из 8")
2. **Иконки для каждого вопроса** — 📊 (компания), 📄 (накладные), 🔄 (процесс), ⏱️ (время), ⚠️ (проблемы), 🎯 (приоритеты)
3. **Карточки результатов** — каждая метрика в отдельной карточке с иконкой, числом и описанием

### Interaction Philosophy
- **Плавные переходы** между вопросами (fade-in/fade-out)
- **Активное состояние кнопки** — становится ярче при наведении
- **Мгновенная валидация** — кнопка "Далее" активируется сразу при выборе ответа
- **Анимация результатов** — карточки появляются с небольшой задержкой (каскадный вход)

### Animation
- **Переход между вопросами**: 300ms fade-in/fade-out (opacity)
- **Появление карточек результатов**: Каскадное появление (каждая карточка +100ms задержка)
- **Hover на кнопках**: Масштабирование (scale 1.02) + изменение тени (200ms ease-out)
- **Прогресс-бар**: Плавное заполнение при переходе на новый шаг (400ms ease-in-out)
- **Иконки**: Лёгкое вращение при загрузке результатов (1s linear infinite)

### Typography System
- **Заголовки**: **Montserrat Bold** (700) — мощный, современный, для названий этапов и метрик
- **Вопросы**: **Montserrat SemiBold** (600) — чёткие, читаемые
- **Текст**: **Inter Regular** (400) — нейтральный, удобный для чтения
- **Описания**: **Inter Light** (300) — вспомогательная информация
- **Размеры**: 
  - Заголовок: 32px
  - Вопрос: 20px
  - Текст: 16px
  - Описание: 14px

### Brand Essence
**Позиция**: Калькулятор, который показывает компаниям реальную экономию от электронных накладных — не просто инструмент, а помощник в принятии решения.

**Три слова**: Ясность, Энергия, Результат

### Brand Voice
- **Заголовки**: Прямые, мотивирующие ("Проверьте, сколько времени вы сможете сэкономить", "Готово! Вот ваши результаты")
- **CTA**: Активные глаголы ("Начать расчет", "Далее", "Узнать больше")
- **Микротекст**: Дружелюбный, поддерживающий ("Нужно для расчета", "Можно выбрать несколько вариантов")

**Примеры фраз**:
- "🚀 Проверьте, сколько времени ваша компания сможет экономить благодаря электронным накладным"
- "За 2 минуты ответьте на несколько вопросов и получите персональные рекомендации"

### Wordmark & Logo
**Логотип**: Минималистичный символ — стилизованный документ с галочкой или стрелка вверх внутри квадрата. Цвет: оранжевый акцент на белом фоне. Без текста (только символ).

### Signature Brand Color
**Оранжевый** (`oklch(0.65 0.25 45)`) — энергия, оптимизм, действие. Используется для кнопок, акцентов и выделения ключевых результатов.

## Стиль-решения (Style Decisions)

- Прогресс-бар всегда видна в верхней части экрана
- Каждый вопрос занимает весь экран (одна тема в фокусе)
- Результаты показываются на отдельном экране с возможностью вернуться и изменить ответы
- Все иконки используют Lucide React для консистентности
- Мобильная версия: полная ширина, увеличенные кнопки, удобный размер текста
