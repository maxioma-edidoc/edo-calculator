# Доступность калькулятора ЭДО в Беларуси без VPN

Веб-приложение калькулятора ЭДО успешно разработано и опубликовано в виде статического фронтенд-приложения. Текущий домен развёртывания (`edocalc-kb4xdjwc.manus.space`) может иметь ограничения на доступ из некоторых регионов без использования средств обхода блокировок.

Чтобы пользователи в Беларуси могли открывать калькулятор **напрямую без VPN**, есть два стандартных и надёжных пути:

## 1. Привязка собственного домена (Custom Domain)
Вы можете привязать собственный домен или поддомен (например, `calc.edidoc.by` или `edo-calc.by`), зарегистрированный в зоне `.by` или другой доступной зоне. 
* В панели управления проектом (Management UI -> Settings -> Domains) можно настроить привязку домена через простые DNS-записи (CNAME / A-записи).
* Это обеспечит прямую доступность для всех клиентов в Беларуси без каких-либо ограничений.

## 2. Экспорт статических файлов и размещение на вашем сервере / хостинге в РБ
Поскольку проект представляет собой чистый статический сайт (React 19 + Tailwind CSS), вы можете в один клик скачать все собранные файлы (через меню Management UI -> Download as ZIP) и разместить их на любом корпоративном веб-сервере или хостинге в Республике Беларусь (например, Hoster.by, ActiveCloud и др.).
* Сайт будет полностью автономен.
* Не потребуется никаких внешних серверных мощностей.
* Обеспечивается 100% скорость загрузки и мгновенный доступ без VPN.
