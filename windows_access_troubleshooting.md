# Устранение проблем с доступом на Windows без VPN

Если сайт открывается на iPhone (Safari), но не открывается на компьютере с Windows без VPN, это обычно связано с особенностями кэширования DNS в Windows, провайдерскими ограничениями резолверов или настройками безопасности (например, корпоративным прокси, антивирусом или защитником Windows).

## Почему такое происходит?
1. **DNS-кэш Windows**: На мобильных устройствах (iPhone) сотовая сеть или Wi-Fi обновляет DNS-запросы динамически. В Windows старый или заблокированный IP-адрес поддомена `.manus.space` может быть жёстко закэширован.
2. **Провайдерские фильтры РБ**: Некоторые белорусские провайдеры (Белтелеком, A1 и др.) по-разному резолвят новые или зарубежные облачные домены.
3. **Браузерные механизмы**: Chrome/Edge на Windows часто используют протокол Secure DNS (DoH — DNS over HTTPS), который может конфликтовать с локальной сетью.

## Как решить проблему на Windows:

### 1. Очистка кэша DNS в Windows
Откройте командную строку (cmd) от имени администратора и выполните:
```cmd
ipconfig /flushdns
```
Затем перезапустите браузер (Chrome / Edge / Firefox) и попробуйте открыть страницу заново.

### 2. Смена DNS-сервера на компьютере
Если провайдер блокирует резолв поддомена Manus, помогите Windows использовать публичные и быстрые DNS:
* Откройте **Панель управления** -> **Сеть и интернет** -> **Сетевые подключения**.
* Нажмите правой кнопкой на ваше подключение (Wi-Fi или Ethernet) -> **Свойства**.
* Выберите **IPv4** -> **Свойства**.
* Установите галочку «Использовать следующие адреса DNS-серверов»:
  * Предпочитаемый DNS: `8.8.8.8` (Google) или `1.1.1.1` (Cloudflare)
  * Альтернативный DNS: `8.8.4.4` или `1.0.0.1`
* Сохраните, очистите кэш DNS (`ipconfig /flushdns`) и проверьте сайт.

### 3. Отключение Secure DNS в браузере (Chrome / Edge)
* В Chrome зайдите в `chrome://settings/security`.
* Найдите раздел «Использовать безопасный DNS».
* Попробуйте временно отключить его или переключить на другого провайдера (например, Cloudflare).

### 4. Использование собственного домена (наиболее стабильный вариант)
Если вы хотите, чтобы сайт открывался у всех пользователей в Беларуси без каких-либо танцев с бубном, идеальный вариант — привязать собственный домен (например, в зоне `.by` или `.ru`) в настройках проекта (Management UI -> Settings -> Domains). В таком случае DNS-запросы будут идти напрямую через белорусские или международные корни без промежуточных облачных поддоменов.
